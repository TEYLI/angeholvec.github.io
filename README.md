# Portfolio Personnel - Ange Holvec

Bienvenue sur le dépôt de mon portfolio professionnel. 
Ce site web a pour but de présenter mon profil, mon parcours en BUT Informatique (IUT Nancy-Charlemagne), mes compétences techniques ainsi que les différents projets que j'ai réalisés au cours de ma formation.

## 🎯 Objectif du projet

- Mettre en valeur mes compétences en développement (Logiciel & Web).
- Présenter mes projets académiques et personnels (Sokoban, Zeldiablo, etc.).
- Faciliter la prise de contact dans le cadre de ma recherche de stage.

## 🛠️ Technologies utilisées

Ce portfolio est construit avec des technologies web standards pour être léger, rapide et facilement hébergeable :
- **HTML5** : Structure sémantique du site.
- **CSS3** : Mise en page et design responsive.
- **JavaScript** : Animations et interactivité.
